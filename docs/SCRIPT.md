## 1. 概念

**深夜,一位 AI 安全研究員的書桌。一顆藍色彈珠在桌上滾了一整首歌,鏡頭從不剪接;每滾過一樣東西,就鑽進去看它代表的概念。同時,一瓶打翻的紅墨水正在淹沒桌面,淹到多少,P(doom) 就是多少。**

- 藍彈珠 = 「我」(歌裡向 AI 求情的那個人)。
- 紅墨水 = P(doom)。
- 開場盯著 webcam 的鏡頭(AI 的眼睛);結尾發現整首歌是 webcam 看出來的畫面。

## 2. 規則

**兩種畫面**

| 模式 | 是什麼 |
|---|---|
| 實景 | 書桌上的實物,3D,只用平塗色塊和網點陰影 |
| 圖解 | 畫在物件表面上的 2D 幾何動畫 |

模式之間只有兩個動作:鏡頭**鑽入**一個表面(表面上的圖放大成全畫面),或圖解**浮出**變回實物。

**顏色:三版油墨**

| 名稱 | 色值 | 用途 |
|---|---|---|
| 紙 | `#F2EBDD` | 底色 |
| 鈷藍 | `#1F3FBF` | 線條、物件、陰影、彈珠 |
| 番茄紅 | `#E8402A` | 只屬於 P(doom):紅墨水,以及每一幕裡危險的那個東西 |
| 藍疊紅 | 兩版相乘,近黑 | 文字與最深的陰影 |

亮面是乾淨色塊(紙白、兩階淺藍平塗或實心),只有陰影用網點。兩版輕微套印錯位,重拍時瞬間加大再彈回;歌詞和小註不參與錯位。

**紅色面積 = P(doom)**

| 時間點 | P(doom) | 紅色佔比 |
|---|---|---|
| 開場 | 0.02 | 只有 webcam 指示燈 |
| Hook 1(23.6 s) | 0.15 | 桌上一灘 |
| Hook 2(60.0 s) | 0.42 | 將近半張桌 |
| Hook 3(96.3 s) | 0.81 | 只剩幾座島 |
| Hook 4(125.4 s) | 0.99 | 只剩幾條白縫 |

數字顯示在桌上的翻頁鐘,每次 hook 翻一次牌。

**鏡頭**:全片一顆鏡頭、零硬切。鏡頭路徑是一條速度連續的曲線,相鄰段落的速度和方向接起來,只在音樂需要停頓時才停。每幕最後一格留下一個形狀、運動或空間,下一幕從它開始;用相同滿版畫面換位置的地方,前後都要有延續的運動。

**驗收標準**:觀眾能一路追蹤同一個物件(主要是彈珠),而且上一幕的動作確實造成下一幕。

**一句一動作**:每句歌詞只有一個觀眾需要看懂的動作,落在該句的關鍵字上。鏡頭運動和變形只在句與句之間做,不和主要動作搶同一拍。

**歌詞是場景裡的物件(全部英文)**

每一句都印在一個承載它的物件上,跟著鏡頭、透視和物件一起動。四條規則:

1. **每句只讓一個關鍵字做主要動作。** 其餘的字只負責被讀,不彈跳、不旋轉。關鍵字用較粗的字重,唱到時觸發畫面動作。
2. **先讀清,再變形。** 正在唱的字保持可辨認;唱完之後才被吞入、撕碎或遮住。長音用持續移動表現(例:`ChatGPT` 的長音期間,紙一直緩慢送進進紙口)。
3. **字幕也要接棒。** 上一句所在的紙、線或標籤是下一幕的入口;上一句自然離場,下一句從承接物件中出現。
4. **構圖為閱讀服務。** 唱到文字時,鏡頭給它足夠大小和較正面的角度。歌詞只用藍版印(未唱是淺藍平塗,唱到變實心藍),所以不受網點和紅藍套印錯位影響。

沒有合適物件可承載時,歌詞印在一張紙標籤上:畫在圖解裡,或立在它所講的物件旁邊、面向鏡頭。

| 類型 | 位置 | 規則 |
|---|---|---|
| 歌詞 | 場景物件上 | 見上方四條 |
| 知識小註 | 左上,固定一行 | 全片 21 則;每則不超過 12 個英文字,至少停留 3 秒;同時最多一則;不套印錯位 |

中文房間的字條用自創的線條符號(Searle 原文稱 squiggles),不出現任何中文字。不出現人臉、真實商標、真實產品介面。

**與原片的區隔**(以下一律不用):橘色火花線、黑底、版畫線條、滿版卡拉 OK 大字、token 機率輸入框、TikZ 獨角獸、燃燒的引信、逐拍下墜的方塊堆疊、Droste 無限縮入、結尾倒帶蒙太奇。
